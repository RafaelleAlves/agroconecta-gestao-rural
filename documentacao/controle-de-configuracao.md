# Gerenciamento de Configuração

## Projeto: AgroConecta

O AgroConecta é um projeto de software voltado à gestão rural.

## Objetivo

Organizar e controlar as alterações realizadas nos arquivos do projeto, mantendo o histórico das versões.

## Ferramenta utilizada

GitHub: plataforma utilizada para armazenar os arquivos, acompanhar alterações e registrar versões do projeto.

## Controle de versões

Cada alteração importante é registrada por meio de um commit, permitindo consultar o histórico do desenvolvimento.

## Organização

Os documentos do projeto ficam armazenados no repositório AgroConecta.
